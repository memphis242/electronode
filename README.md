# `electronode` - a wireless EMG sensor
This is a project where I plan to develop an open-source wireless EMG sensor and
refine it in phases:

1. µC BLE dev board, reads EMG + IMU, broadcasts data over BLE
    - EMG will be third party electrode + amplifier
2. upgrade the dev board into a battery-powed custom PCB and refine the MCU
   firmware
3. add in a desktop TUI application + display
4. refine the sensor PCB
5. enhance the amplifier with your own specific electronic design
6. multi-sensor time
7. enhance signal processing through statistics that accounts for other sensor
   proximity
8. full-limb sensor mesh /w comparison to neuromuscular simulation
